### 2026-06-02 — Sloth Bytes
- **Lesson:** Binary-search midpoint gotcha: `mid = (left + right) // 2` can integer-overflow in Java/C on large indices; the safe form is `mid = left + (right - left) // 2`. Python ints don't overflow, but this exact bug lived in Java's standard library for 9 years — know it if you ever port logic to/from C/Java.
