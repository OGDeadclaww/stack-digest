### 2026-02-25 — Sloth Bytes
- **Lesson:** Dijkstra's shortest-path reference pattern using a priority queue (`heapq`): start node cost 0, every other node cost infinity, repeatedly pop the lowest-cost unvisited node, relax its neighbors' costs if a cheaper path was just found, stop once you pop the destination. Guarantees shortest path in a weighted graph every time.
